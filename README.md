# Repository Overview
A repository containing all personal projects for learning development with LLMs

# Project List
1. day_1_agent.py : A multi-agent AI assistant system that randomly changes personality. Key skills learned - development with Google's Agent Development Kit, agent-as-a-tool multi-agent configuration

2. offline_ollama : A simple program that calls the api of a locally-run LLM via Ollama and stores the LLM response back into a variable in the program for further processing
